# Nandemo-FBX

MMD（PMX / VMD）や VRM / VRMA を FBX に変換するツールです。Rust で書かれていて、外部ソフト（Blender や FBX SDK）なしで動きます。

> 開発初期の段階です。PMX のメッシュ・ボーン・スキン・モーフ（ブレンドシェイプ）と、VMD のボーンアニメーション（IK・付与親を焼き込み済み）・モーフアニメーションを FBX に書き出せます。

## 使い方

```sh
cargo run --release -- model.pmx                         # model.fbx を書き出す
cargo run --release -- model.pmx -o out/model.fbx
cargo run --release -- model.pmx -m dance.vmd            # モデル＋アニメーション
cargo run --release -- model.pmx -m dance.vmd -e anim    # ボーンとアニメーションだけ
cargo run --release -- model.pmx -m dance.vmd -e model   # モーションを無視してモデルだけ
```

`-e` / `--export` で書き出す内容を選べます。

| 値 | 書き出す内容 |
|---|---|
| `all`（既定） | メッシュ・マテリアル・ボーン・スキン・ブレンドシェイプ・アニメーション（`-m` 指定時） |
| `model` | メッシュ・マテリアル・ボーン・スキン・ブレンドシェイプ |
| `anim` | ボーンとボーンアニメーションだけ（`-m` が必要）。モデルはボーン構造を得るために使います。メッシュがないので、モーフのアニメーションは含まれません |

ボーンアニメーションは毎フレームの値を焼き込んだあと、誤差が許容値以下になる範囲でキーを減らします（既定は移動 0.1 mm・回転 0.01°）。モーフアニメーションは VMD のキーをそのまま書き出します。モデルにないボーン・モーフのモーションは無視し、警告を出します。

### モーフ

頂点モーフをブレンドシェイプとして書き出します。グループモーフは、含まれる頂点モーフを割合を掛けて足し合わせた 1 つのブレンドシェイプにします。ボーン・UV・材質モーフは FBX のブレンドシェイプにできないので書き出しません（グループモーフに含まれている場合も、その部分は無視します）。

### キーの間引き

| オプション | 内容 |
|---|---|
| `--tolerance-mm <mm>` | 移動の許容誤差（既定 0.1） |
| `--tolerance-deg <度>` | 回転の許容誤差（オイラー角の各成分、既定 0.01） |
| `--no-reduce` | キーを減らさず、全フレームのキーを書き出す |

カーブの成分ごとに、元のどのフレームでも、線形補間した値との差が許容誤差以下になることを保証します。ボーン 250 本・6000 フレーム（キーは 30 フレームおき）のテストデータでは、14.9 MB が 1.7 MB になりました（全ボーンの位置の差は最大 0.5 mm）。キーが細かいモーションほど減り方は小さくなります。

### IK・付与親

FBX には MMD の IK・付与親にあたる仕組みがないので、モデルに IK か付与親があれば、計算したポーズを焼き込みます。計算の順序は次のとおりです。

1. 各ボーンにアニメーションの値を設定する
2. IK を変形階層の順に CCD 法で解く（VMD の IK 有効/無効の切り替えに対応）
3. 付与親の回転・移動を変形階層の順に加える

ひざのように 1 軸だけ動けるリンクは、その軸まわりの角度で解きます。脚がほぼまっすぐのときは CCD 法ではひざが曲がりにくいので、ひざ＋太ももの 2 リンクの IK は、届かなかった場合に距離からひざの角度を求めて補正します。

物理演算（剛体）はまだ反映しません。

## 対応状況

| 形式 | 読み込み | FBX への書き出し |
|---|---|---|
| PMX | 頂点・面・テクスチャ・マテリアル・ボーン・モーフ | メッシュ・マテリアルの色・ボーン・スキン・バインドポーズ・ブレンドシェイプ（頂点・グループモーフ） |
| VMD | ボーン・モーフ・IK 切り替えのキーフレーム（ベジェ補間付き） | ボーンアニメーション・モーフアニメーション |
| VRM | 未対応 | 未対応 |
| VRMA | 未対応 | 未対応 |

## 構成

```
crates/
  nandemo-core  中間表現（IR）とバイナリリーダー
  nandemo-pmx   PMX リーダー（PMX → IR）
  nandemo-vmd   VMD リーダー（VMD → IR）
  nandemo-fbx   FBX ライター（IR → FBX バイナリ 7.4）
  nandemo-cli   コマンドラインツール（実行ファイル名は nandemo-fbx）
```

各リーダーは入力を IR に変換し、FBX ライターは IR だけを見て書き出します。座標系と単位の変換はリーダー側で一度だけ行います。

IR の規約（glTF / VRM 1.0 と同じ）:

- 右手系・Y-up・モデルの正面は +Z
- 単位はメートル（MMD の 1 単位 = 0.08 m として換算）
- UV は左上原点、三角形は反時計回りが表面

FBX の出力は Y-up・正面 +Z・センチメートル単位です。

## テスト

```sh
cargo test
```

FBX ライターのテストでは、書き出したファイルを [ufbx](https://github.com/ufbx/ufbx)（厳密モード）で読み戻して検証しています。
